**RC9 为候选测试版本，修复大金 G3 免拆迁移临时 MQTT 证书并更新教程。升级前备份配置，按型号与变体选择镜像。**

**RC9 is a release candidate that fixes the temporary MQTT certificate used by the Daikin G3 wireless migration tool and updates the tutorial. Back up configuration and select the matching model and variant.**

- **G3 免拆迁移证书 / G3 wireless migration certificate**：迁移工具生成的临时证书现在明确声明为 CA，并带有 MQTT 服务端用途与三个原厂域名的 SAN。教程会先检查 `CA:TRUE`；旧工具生成的证书按修复步骤替换后再继续。首次连接允许少量重试，但必须看到 `New client connected ... as SENSOR:<STA_MAC>`。
  The migration tool now marks its temporary certificate as a CA, adds the MQTT server usage and includes SANs for all three factory domains. The tutorial checks for `CA:TRUE` and gives a repair path for certificates generated by older archives. A few initial retries are allowed, but the broker must show `New client connected ... as SENSOR:<STA_MAC>` before continuing.
